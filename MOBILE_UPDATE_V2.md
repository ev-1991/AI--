# KazONCO AI — Mobile UX v2

Доработан мобильный интерфейс пациента для экранов до 760 px и Expo-версии.

## Что изменено

- Верхняя шапка стала компактнее и занимает меньше высоты.
- Основные вкладки пациента: «Чат», «Пациент», «Безопасность».
- Кнопка «Выйти» убрана из основного экрана чата и перенесена в меню профиля.
- Для выхода добавлено подтверждение, чтобы пациент не завершал сеанс случайно.
- Переключение RU / KZ / EN перенесено в меню профиля; в шапке оставлен компактный значок языка.
- «Маршрут» сделан компактной плавающей кнопкой и открывается поверх чата как нижняя панель, не уводя пациента со страницы переписки.
- Поле ввода остаётся в нижней части чата; добавлена адаптация высоты под мобильную клавиатуру через Visual Viewport API.
- Информационный текст безопасности свёрнут в короткую строку и раскрывается по нажатию.
- Добавлен индикатор «Поиск в базе знаний…» перед формированием ответа.
- Под ответом AI показан маркер «Ответ по базе знаний КазНИИОиР» и кнопка просмотра источника.
- Добавлена кнопка быстрого возврата к последнему сообщению при прокрутке истории вверх.
- Добавлено уведомление об отсутствии интернет-соединения. Введённый текст при этом не очищается.
- Размер текста сообщений и поля ввода на мобильном увеличен до комфортных значений.
- Быстрые вопросы сделаны горизонтально прокручиваемыми, чтобы не занимать большую часть экрана.

## Основные файлы

- `index.html` — новая мобильная шапка, профиль, маршрут, статусы чата.
- `styles.css` — Mobile UX v2.
- `app.js` — профиль, выход с подтверждением, offline-состояние, AI-status, источник, прокрутка вниз.
- `mobile-expo/App.js` — аналогичные изменения для Expo/Android.
