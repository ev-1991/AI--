# KazONCO AI — помощник пациента

Прототип включает веб-версию и мобильное приложение Expo/React Native. Пациент входит по ФИО, открывает чат и задаёт вопрос или описывает симптом простыми словами.

## Что добавлено

- режим «вопрос — ответ» для пациента;
- база знаний по группам препаратов при НМРЛ;
- справочная информация о нежелательных явлениях таргетной и иммунотерапии;
- быстрые вопросы о симптомах и препаратах;
- автоматическое распознавание опасных признаков;
- передача вопроса врачу, если информации недостаточно или пациент просит изменить лечение;
- безопасный шаблон описания симптома.

## Источники наполнения

- «НЯ таргетная иммунотерапия НМРЛ»;
- «Приложение по НЯ технической задачи»;
- «Препараты РЛ».

Материалы адаптированы для пациентского языка. Подробные схемы и дозировки намеренно не выдаются как персональная рекомендация.

## Запуск веб-версии

Откройте `index.html` в современном браузере. Для корректной работы файлов удобнее запустить локальный сервер:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Запуск мобильной версии

```bash
cd mobile-expo
npm install
npm run start
```

## Ограничение

AI-помощник не ставит диагноз, не назначает и не отменяет лечение, не меняет дозировку и не заменяет лечащего врача. При резком ухудшении состояния пациенту необходимо обращаться за срочной медицинской помощью.
