# Обновление мобильного интерфейса

Обновлена мобильная версия KazONCO AI без изменения основной логики приложения.

- компактная верхняя шапка KazONCO AI;
- вкладки пациента вынесены в удобную мобильную навигацию;
- чат занимает основную часть экрана и больше не перекрывается большой боковой панелью;
- история чатов открывается кнопкой ☰;
- поле ввода закреплено внутри области чата и остается удобным на небольшом экране;
- блок с правилом безопасности перенесен под чат и сделан компактным;
- кнопки «Маршрут» и «Выйти» вынесены под чат и не накладываются на сообщения;
- «Маршрут» раскрывает схему движения пациента без перехода с текущего чата;
- добавлен компактный переключатель RU/KZ/EN;
- обновлена мобильная Expo-версия: компактная шапка, светлые сообщения пациента, новый composer, нижние действия «Маршрут» и «Выйти».

Для GitHub Pages достаточно заменить `index.html`, `styles.css`, `app.js` и папку `assets` файлами из архива.
