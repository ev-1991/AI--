# KazONCO AI Mobile

Мобильное приложение AI-агента КазНИИОиР на Expo / React Native.

## Возможности

- вход пациента по ФИО и ИИН;
- чат пациента с AI-агентом;
- режим «AI-помощник пациента — вопрос и ответ» с быстрыми вопросами;
- ответы по нежелательным явлениям таргетной и иммунотерапии НМРЛ;
- распознавание «красных флагов» и передача обращения врачу;
- ответы врача, администратора, директора и супер-администратора;
- отправка фото и документов;
- просмотр фото в увеличенном виде;
- раздел FAQ;
- навигация по КазНИИОиР;
- история обращений пациента;
- кабинет сотрудника;
- управление базой знаний;
- кабинет супер-админа;
- аналитика;
- журнал действий.

## Запуск

```bash
npm install
npm run start
```

Для запуска на Android:

```bash
npm run android
```

## Сборка AAB для Google Play

Установите EAS CLI и авторизуйтесь:

```bash
npm install -g eas-cli
eas login
```

Сборка Android App Bundle:

```bash
npm run build:aab
```

## Важно

- AI отвечает только на основании утвержденной базы знаний КазНИИОиР.
- В базу прототипа добавлены пациентские материалы из документов «НЯ таргетной и иммунотерапии НМРЛ», «Приложение по НЯ технической задачи» и «Препараты РЛ».
- AI не ставит диагноз, не назначает лечение и не заменяет врача.
- Запросы о назначении, отмене, замене препарата или изменении дозировки автоматически передаются специалисту.
- ChatGPT/OpenAI нужно подключать через серверный API. Нельзя хранить `OPENAI_API_KEY` в мобильном приложении.
- Push-уведомления в прототипе описаны интерфейсно; для production потребуется сервер уведомлений и Expo Push Notifications или Firebase Cloud Messaging.
